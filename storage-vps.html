— FAQ

Questions, answered.

How much storage can I get?
Standard Storage VPS plans run from 250 GB up to 2000 GB, and our high-volume plans reach 3000 GB and 4000 GB (4 TB). Every plan ships with unlimited bandwidth. Need more than 4 TB? Submit a quote request and we'll build something custom.
Is Microsoft Windows Server really free?
Yes. We include Microsoft Windows Server for KVM customers at no additional cost — select from Server 2003, 2008 R2 or 2012 versions. Prefer Linux or BSD? Choose from our 100+ pre-built templates instead.
Is the storage SSD or HDD?
Storage VPS plans use large RAID-60 spinning drive arrays — a minimum of 16 drives per server — which is exactly what keeps the cost-per-gigabyte so low. If you need pure-SSD performance instead, choose our Dedicated KVM Slices.
What's the difference vs. Block Storage Slabs?
A Storage VPS is a complete, self-contained server with CPU, RAM and a large RAID-60 disk — boot it, install an OS and go. A Block Storage Slab is add-on space that attaches to an existing VPS at $1.25/mo per 256 GB. Want one big box? Use a Storage VPS. Just need cheaper bulk space on a server you already run? Add a Slab.
Can I get more than 4 TB of storage?
Our high-volume plans top out at 4 TB off the shelf. If you need something larger or a different configuration, submit a quote request and we'll put together a custom build for you.
