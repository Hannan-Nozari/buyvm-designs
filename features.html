— FAQ

Questions, answered.

What exactly is Stallion?
Stallion is BuyVM's in-house control panel — the one we built for ourselves and kept improving for over a decade. It handles deploy, reinstall, rebuild, snapshots, rescue mode and a VNC console, with real cloud-init and a full API behind it. Customers keep voting it the best panel on the market, and we're inclined to agree.
Do you really include DirectAdmin for free?
Yes — every slice with 1 GB of RAM or more comes with a free DirectAdmin license, no promo code and no expiry. Smaller slices can add one, and Softaculous and Blesta licenses are available across the board if you want them.
Is there an API?
There is, and it's the real thing — every action you can take in the panel, you can script. Deploy slices, trigger snapshots, manage networking and more, straight from your own tooling or CI pipeline.
Do you support cloud-init?
We do, properly. Pass user-data at deploy time to configure users, SSH keys, packages and bootstrap scripts so a slice is fully provisioned the moment it boots — no manual first-login ritual.
